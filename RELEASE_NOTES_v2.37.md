# SCM IDP Dashboard v2.37 Release Notes

## Operations Excellence Presentation Export Redesign
- The Executive Presentation export now uses the approved **Operations Excellence** dark-navy / gold visual system supplied by the user.
- Cover slide uses the supplied **Inventory and Distribution Planning Department - SCM** globe/network artwork and renders the latest KPI source date dynamically.
- KPI export pages now use the supplied KPI design as the official layout reference:
  - one KPI per full slide;
  - Operations Excellence / Supply-Sales-Support-Growth header;
  - gold + white KPI title hierarchy;
  - current KPI value and latest-vs-previous direction card;
  - YTD/Weekly Average, High and Low summary;
  - large Actual + Trend line graph with point labels;
  - management action strip and executive footer.
- All six configured KPIs are exported in both **YTD** and **Weekly** versions, including **MUTI MC : Stock Outrate - Overall (Before PO Balance)**.
- KPI-specific favorable-direction rules are preserved in the presentation:
  - stock-out KPIs: lower is better;
  - MC Class A DoI: higher is better;
  - MUTI MC DoI: balanced/coverage monitoring.
- DoI values continue to follow the approved upward/ceiling rounding rule.
- Existing ABC Model Position, Area Performance, Branch rankings and branch model-detail export sections remain included after the redesigned KPI pages.
