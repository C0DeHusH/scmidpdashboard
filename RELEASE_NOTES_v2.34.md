# SCM IDP Dashboard v2.34

Delivery Plan usability update:
- Weekly Truck Schedule is collapsible and can be reopened with View / Open.
- Allocation Import is collapsible and can be reopened with View / Open.
- Save Schedule + Allocation automatically minimizes both input sections after a successful save.
- A Saved Delivery Plan Inputs bar provides direct View Weekly Schedule and View Allocation Import actions.
- Clear Board clears both Weekly Truck Schedule and Allocation data while preserving delivery masterlists.
- Weekly Truck Schedule Export Template control and obsolete export route were removed.
