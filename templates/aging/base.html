Data Dictionary

Unit-Level Column Guide

How to interpret every field shown in the aging table.

BranchThe branch currently holding or assigned to the motorcycle unit.
AreaThe geographic or operational cluster where the branch belongs.
Standard DescriptionThe standard model description used to group the same motorcycle model consistently.
BrandThe motorcycle manufacturer or supplier brand.
Engine No.The unique engine identification number used for traceability.
ChassisThe unique frame or chassis number of the unit.
Created OnBranch-level aging basis date.
Incoming DateCompany-level aging basis date.
Age DaysExact days from the selected basis date to the As-of Date.
QtyNumber of motorcycle units represented by the row.
ValueInventory value represented by the row.
LocationOriginal location reference from the import file.
