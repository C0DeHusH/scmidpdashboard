# Release Notes v2.35

## Delivery Plan — protected saved weekly plan

- Corrected **Clear Board** behavior. It now clears only the current working/on-screen Weekly Truck Schedule and Allocation view.
- **Saved Schedule + Allocation for the Week is not deleted by Clear Board.**
- Saved plan can be restored/reopened with **View Weekly Schedule** and **View Allocation Import**.
- Added a protection guard so a blank board immediately after Clear Board cannot accidentally overwrite the saved weekly plan through **Save Schedule + Allocation**.
- The saved-plan bar now explicitly identifies the weekly plan as **Protected**.
- Explicit **Clear Allocations** remains a separate destructive action and preserves the Weekly Truck Schedule.
